# Comuni（可优笔记）小程序使用说明书（v0.0.2）

## 一、产品介绍

Comuni（可优笔记）是一款轻量化、全功能开放的Markdown共享知识平台。
你可以用它轻松创作、编辑、管理个人Markdown笔记，也能浏览平台内其他用户公开分享的优质知识内容，结识同好创作者。*
*平台所有核心功能对所有用户开放，无任何付费功能墙，无功能使用门槛**。

「尊贵会员」标识仅为对平台技术捐赠支持者的象征性荣誉标识，不附加额外功能特权，所有用户均可无差别使用平台全部能力。

## 二、快速入门（新用户必看）

### 2.1 如何进入小程序

两种方式一键进入：

1. 微信首页下拉，在搜索框输入「Comuni可优笔记」，点击对应小程序即可进入；
2. 扫描官方分享的小程序二维码，直接跳转进入。

### 2.2 注册与登录

平台提供两种登录方式，均安全合规，不会泄露你的个人信息：

#### 方式一：微信一键登录（推荐）

1. 进入小程序后，点击首页「微信一键登录」按钮；
2. 在弹出的微信授权弹窗中，点击「允许」；
3. 授权完成后自动完成注册+登录，直接进入平台主界面，无需手动设置账号密码。

#### 方式二：账号密码登录(内测资格)

适合已有平台账号的用户使用：

1. 进入登录页，选择「账号密码登录」；
2. 输入你注册的账号、密码；
3. 点击「登录」按钮，验证通过后即可进入主界面。

> 提示：若登录失败，可先检查手机网络是否正常，切换WIFI/移动数据后重试；仍有问题可查看文末「常见问题」或`联系我们`。

### 2.3 主界面总览

小程序底部有4个核心导航栏，覆盖全部使用场景：
| 导航栏 | 核心功能 |
| ------ | ---------------------------------------- |
| 首页 | 搜索优质公开笔记，支持搜索内容/用户 |
| 知识库 | 笔记编辑页，新建、编辑Markdown笔记，保存 |
| AI助手 | 在文章内点击`问AI` 即可提问文章内容 |
| 我的 | 个人中心，管理个人资料、关注、粉丝 |

## 三、核心功能详细使用指南

### 3.1 笔记创作与管理（核心功能）

平台原生支持完整Markdown语法，移动端也能轻松写出排版专业的笔记。

#### 3.1.1 新建笔记

1. 点击`我的知识库` `文章列表`导航栏「+」按钮，添加知识库/笔记；
2. 输入笔记标题、正文内容，编辑器支持以下常用Markdown语法：
    - 标题：# 一级标题、## 二级标题，最多支持6级标题
    - 列表：有序列表（1. 2. 3.）、无序列表（- 内容）
    - 格式：**加粗**、*斜体*、`行内代码`、> 引用块
    - 图片：支持直接插入手机相册图片，自动生成Markdown图片链接

#### 3.1.2 发布与保存

- 「私有知识库保存」：仅自己可见，不会发布到知识广场，后续可继续编辑，适合存放个人私密笔记；
- 「公开知识库发布」：笔记保存即同步到知识广场，其他用户可浏览、评论。

#### 3.1.3 笔记管理

1. 进入「知识库」-「我的知识库」，可查看你所有的知识库、公开、私密笔记；
2. 点击单篇笔记，可进行「编辑」「修改发布状态」「删除」操作；
3. 支持按标题、发布时间筛选笔记，快速找到目标内容。

### 3.2 知识广场与内容浏览

#### 3.2.1 浏览推荐内容

1. 进入「首页」，即可看到平台推荐的优质公开笔记，下滑可无限加载；
2. 点击单篇笔记，即可进入详情页查看完整内容，支持放大图片、复制文本。

#### 3.2.2 搜索知识库/文章

1. 点击首页顶部搜索框，输入关键词；
2. 可选择「搜知识库」「搜笔记」「搜用户」两个维度，精准找到你需要的内容或创作者；
3. 关注：将公开优质知识库加入`关注知识库`，后续在「知识库」-「关注/分享的知识库」中可快速查看；
4. 将搜索到的文章复制到选择的`我的知识库`

#### 3.2.3 内容互动

在笔记详情页，你可以进行以下操作：

- 评论：为优质内容提供宝贵意见，表达认可；
- 问AI：点击作者头像，进入个人主页，点击「关注」按钮，即可持续收到该作者的新内容更新。
- 一键复制优质文章编辑

### 3.3 社交互动功能

#### 3.3.1 关注与粉丝管理

1. 进入「关注」页，可切换查看「关注列表」「粉丝列表」；
2. 关注列表：查看你已关注的所有用户，点击可进入对方主页，也可直接「取消关注」；
3. 粉丝列表：查看关注你的所有用户，可「移除粉丝」。

### 3.4 个人中心与资料设置

#### 3.4.1 个人资料修改（修改后重新登录）

1. 进入「我的」页面，点击头像或「编辑资料」按钮，进入资料编辑页；
2. 可修改以下信息：
    - 头像：从手机相册选择图片上传
    - 昵称：支持2-20位汉字、字母、数字、下划线，不可与其他用户重复
    - 用户ID：支持8-32位字母、数字组合，不可与其他用户重复
    - 个人简介：最多200字，介绍你的个人情况、知识库方向
    - 性别、隐私设置：可设置账号是否为私密状态（私密账号的内容仅自己可见）
3. 修改完成后，点击「保存」即可生效。

#### 3.4.2 账号与安全

- 绑定微信：可在「我的」-「账号安全」中绑定微信，后续可一键登录
- 密码修改：账号密码登录的用户，可通过原密码修改新密码
- 账号注销：可提交账号注销申请，7天冷静期后完成注销，所有数据将被清空。

### 3.5 捐赠支持与会员标识

#### 3.5.1 核心说明

平台所有功能免费开放，无任何付费强制要求。「尊贵会员」标识仅为对平台支持者的象征性荣誉感谢，无任何额外功能特权，不影响正常使用。

## 四、常见问题（FAQ）

### Q1：微信一键登录失败，提示“登录异常”怎么办？

A：可按以下步骤排查：

1. 检查手机网络是否正常，切换WIFI/移动数据后重试；
2. 关闭小程序，从微信最近使用列表中移除，重新进入重试；
3. 确认微信授权弹窗中点击了「允许」，未拒绝授权；
4. 若仍无法解决，可通过官方邮箱联系我们处理。

### Q2：捐赠后没有显示「尊贵会员」标识怎么办？

A：

1. 先确认是否在工作日处理时段，非工作时段会顺延至次日；
2. 若超过24小时仍未显示，可发送邮件至skixkk7@163.com，附上「捐赠截图+你的注册邮箱/用户ID」，我们会在1个工作日内为你手动补充。

### Q3：编辑的笔记内容丢失了怎么办？

A：

1. 建议编辑长笔记时，定期手动点击「保存」，避免意外情况导致内容丢失；

### Q4：可以修改已经发布的笔记吗？

A：完全可以。进入「知识库」-「有编辑权限的知识库」，找到需要修改的笔记，点击「<img src="https://youupro.xyz/notes/static/icons/compile.png" alt="编辑" style="zoom:25%;" />」按钮，修改完成后可重新选择发布状态，点击保存即可更新。

### Q5：怎么让我的笔记不被其他人看到？

A：

1. 添加知识库时，选择「私有」，创建保存后仅自己可查看，不会出现在知识广场；

### Q6：我的用户ID可以修改吗？有什么限制？

A：可以修改。进入「我的」-「编辑资料」-「用户ID」即可修改，限制如下：

1. 仅支持8-32位字母、数字组合，不支持特殊符号、汉字；
2. 不可与平台内其他用户的ID重复；
3. 修改后立即生效，原ID会被释放，其他人可注册使用。
4. 退出登录，重新登录。
